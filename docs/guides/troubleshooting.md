# トラブルシューティング

ジョブが止まったときは、まずコンソール（またはログファイル）の最後の `[ERROR]` 行と、その直前の `[WARNING]` 行を読みます。止まった理由のほとんどは、そこに書かれた条件名・件数・パスで特定できます。

## 1. ブラウザに接続できない・タブが見つからない

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `ブラウザのデバッグ用ポートに接続できません（http://localhost:9222/json）` | ブラウザがリモートデバッグ付きで起動していない。ポートが違う。同じプロファイルの別ウィンドウが先に開いていて、デバッグ用ポートが開かなかった | ブラウザをすべて閉じ、`--remote-debugging-port=9222 --user-data-dir=<専用フォルダー>` 付きで起動し直す。`Common.Browser.DebuggerUrl` のポートを合わせる |
| `操作できるタブが見つかりません` | 業務画面のタブが無い（新しいタブ・拡張機能・設定画面だけ） | 対象の画面を開く |
| `対象の画面と一致するタブが見つかりません` | 開いている画面が、ジョブの対象画面の識別条件を満たさない | 直前の `[WARNING]` に、タブごとの `満たしていない条件: <条件名>「<説明>」` が出る。下の「画面識別の条件」を見る |
| `対象の画面と一致するタブが複数あります` | 同じ画面が2つ以上のタブで開いている | 1つだけ残して閉じる |

### 画面識別の条件

| 条件名 | 意味 | よくある原因 |
|---|---|---|
| `identity.app.name` | 製品名（温室コンソール / 作付け台帳）が画面にある | 別の製品・ログイン画面を開いている |
| `identity.nav.section.unique` / `identity.nav.section.current` | メインメニューの「区画」が1つで、現在地になっている | 別のメニュー（ダッシュボードなど）を開いている |
| `identity.group.default.selected` | グループツリーで「全区画（既定）」だけが選ばれている | 別のグループ（第1温室など）を選んでいる |
| `identity.view.unique` / `identity.view.plotList` | 作付け台帳の本体が区画一覧である | 資材一覧など、似た別の一覧を開いている |
| `identity.title.plotList` | 見出し・パンくず・タイトルに「区画一覧」がある | 同上 |

条件の一覧と、画面のどの要素を見ているかは [page-contracts.md](../browser/page-contracts.md) にあります。画面の作りが変わって条件を満たせなくなった場合は [changing-page-contracts.md](changing-page-contracts.md) を参照してください。

## 2. 画面の契約違反

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `ページ契約違反: <確認の名前>` に続いて `[fatal] <条件名>: <説明>` | 操作の前提となる画面の要素が無い、またはちょうど1つに決まらない | 条件名を [page-contracts.md](../browser/page-contracts.md) で引く。画面の表示状態（メニュー・ダイアログ・絞り込み）を見直して再実行する。画面の仕様が変わったなら契約の更新を検討する |
| `ページ契約の注意: …` に続いて `[warning] …` | 続行できるが、確認しておくべき状態（例: 表示中の行に選択済みの区画が無い） | 内容を確認する。止まらない |
| `チェック操作に使う一覧の範囲を決められません。理由=no_valid_pane` など | 一覧の左固定ペイン・通常ペインのどちらで操作すべきか決められない | `理由` を [page-contracts.md](../browser/page-contracts.md#温室コンソール区画一覧) の「操作スコープ」で引く |
| `操作 X の契約 scope が一致しません` / `戻り値が契約結果の形ではありません` | 操作カタログとページスクリプトの不整合（開発時の誤り） | 該当ジョブの `PageOperations.psd1` とページスクリプトを見直す |

## 3. ブラウザとの通信が切れた

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `ブラウザ側で WebSocket が閉じられました` / `ブラウザとのセッションは既に閉じています` | 実行中にタブやブラウザが閉じられた | 開き直して再実行する |
| `ブラウザの応答がタイムアウトしました。method=Runtime.evaluate` | 画面が固まった・処理が重い | 画面を再読み込みして再実行する。続くなら `Common.Browser.CommandTimeoutSeconds` を延ばす |
| `[pagekit:helper-missing] ページヘルパー 'xxx' が登録されていません` | 実行中に画面が再読み込み・遷移し、注入したスクリプトが消えた | 実行中にブラウザを操作しない。画面が自動で再読み込みされる設定なら止める |
| `ブラウザとの通信を続けられないため停止します。区画=…` | 上記のどれかが区画の処理中に起きた | 原因を取り除いて再実行する（週次は何度実行しても同じ結果になる） |

## 4. ダウンロード

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `ダウンロードの完了を確認できませんでした（120 秒）` | ダウンロードが始まらなかった（保存先を尋ねるダイアログ、ダウンロードのブロック）。名前が `DownloadedFilePattern` / `DownloadFilePrefix` に合わない。時間がかかりすぎる | ブラウザの「ダウンロード前に保存場所を確認する」を無効にする。画面がダウンロードさせるファイル名を確認して設定を合わせる。必要ならタイムアウトを延ばす |
| `ダウンロード先に候補ファイルが複数あります` | 一時ダウンロード先に他のファイルが置かれた | 一時ダウンロード先を、そのジョブ専用のフォルダーにする |
| `ダウンロードしたファイルが 0 バイトです` | 画面が空のファイルを返した | 画面側の状態を確認する |

## 5. 週次: SoilAnalysisTargetSync

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `CSV データエラーが N 件あります` | 判定できない行・区画コードの空欄や重複がある。**画面には触れていない** | `soil_analysis_csv_errors.csv` の `Code` を下の表で引く |
| `CSV の行数と一覧の件数が一致しません。CSV=… 一覧=…` | 絞り込み欄に文字が入っている。CSV が古い。出力から整合までの間に区画が増減した | 絞り込みを解除し、週次の連携ジョブを最初から実行する |
| `処理は最後まで行いましたが、失敗が N 件あります` | 一部の区画を揃えられなかった、または走査結果が CSV と食い違った | `soil_analysis_sync_failures.csv` の `Code` を下の表で引き、原因を直して再実行する |

| Code | 意味 |
|---|---|
| `ANALYSIS_DATE_INVALID` / `MEASURED_DATE_INVALID` | 土壌分析の完了・最終計測日時を日付として読めない |
| `DATE_ORDER_INCONSISTENT` | 最終計測日時が土壌分析の完了より前（記録の矛盾） |
| `PLOT_CODE_BLANK` / `PLOT_CODE_DUPLICATED` | 区画コードの空欄・重複 |
| `UI_TOTAL_COUNT_INVALID` / `CSV_UI_COUNT_MISMATCH` / `TARGET_UI_COUNT_MISMATCH` | 画面の件数が読めない・CSV と合わない（操作前に停止） |
| `SYNC_FAILED` / `SYNC_EXCEPTION` | その区画のチェックを目的の状態にできなかった（詳細は `Reason`） |
| `PLOT_NOT_FOUND_IN_UI` / `PLOT_NOT_IN_CSV` | CSV と画面で区画の集合が違う |
| `UI_ROW_WITHOUT_KEY` / `UI_PLOT_CODE_CONFLICT` / `UI_SEEN_COUNT_MISMATCH` | 画面の行の識別が一貫しない（行 ID・区画コードの欠落や食い違い） |
| `SCAN_LOOP_LIMIT` / `SYNC_NOT_ATTEMPTED` / `PROCESSED_COUNT_MISMATCH` | 走査が最後まで届かなかった |
| `ON_SUCCESS_COUNT_MISMATCH` / `OFF_SUCCESS_COUNT_MISMATCH` / `SUCCESS_NOT_ALIGNED` | 成功の件数・状態が対象と合わない |
| `REQUEST_MENU_NOT_ENABLED` | 区画を選んだのに「土壌分析を依頼」が有効にならない |
| `FATAL_ERROR` | 上記以外の理由で途中停止した（`Reason` に例外の内容） |

すべての Code の判定箇所は [soil-analysis-target-sync.md](../jobs/soil-analysis-target-sync.md#失敗の記録) にあります。

## 6. 月次: PlantingRecordExport / LastMonthPlantingDigest

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `ページ契約違反: 一覧の件数 N 件に対して、処理できたのは M 件です（終了理由: end-of-list）` | 一覧を最後までスクロールできなかった | 画面の表示倍率・ウィンドウの大きさを戻す。`StallLimit` を増やす |
| `処理に失敗した区画が N 件あります` | 一部の区画で保存に失敗した | `failed_planting_exports.csv` の `Reason` を確認して再実行する |
| `連携エラー: PlantingRecordExport の成果物 CSV（planting_*.csv）が保存先にありません` | 画面がダウンロードさせるファイル名が `DownloadFilePrefix` で始まらない | 設定の `DownloadFilePrefix` を合わせる |
| 集計の失敗一覧に `対応していない文字コード（推定: Shift_JIS）` | CSV が UTF-8 / UTF-16 / UTF-32 以外で保存されている | 作付け台帳の出力形式を UTF-8 にするか、ファイルを UTF-8 で保存し直す |
| 集計の失敗一覧に `見出しが一致しません` | 見出し行が `RequiredHeaders` と順序まで含めて一致しない | 画面の出力形式を確認する。仕様が変わったなら設定を更新する |
| 集計の失敗一覧に `定植日を日付として読めないため行を飛ばしました` | 定植日が空欄・日付でない | 作付け台帳の記録を直す |

## 7. 設定・ファイル

| メッセージ（抜粋） | 原因 | 対処 |
|---|---|---|
| `設定 Jobs.X.Y がありません` / `… は整数で指定してください` | settings.psd1 の項目の欠落・型違い | [configuration.md](configuration.md) を見て直す |
| `… ディレクトリにユーザープロファイル直下のフォルダーは指定できません` | 出力先が安全の規則に反する | 専用のフォルダーを作って指定する |
| `ジョブ定義にないジョブ名です` | .bat や `-JobName` の綴り違い | jobs.psd1 のジョブ名を確認する |
| Windows PowerShell 5.1 で構文エラー・文字化けが出る（PowerShell 7 では動く） | ソースが BOM なしの UTF-8 で保存された | `powershell -File tools\Repair-SourceEncoding.ps1` を実行する（[powershell-compatibility.md](powershell-compatibility.md)） |
| `ジョブ 'X' は結果オブジェクトを1つだけ返す必要があります（実際: 2 個）` | ジョブのコードがパイプラインに値を出している（開発時の誤り） | 戻り値を捨てる呼び出しに `[void]` を付ける |

## この文書を更新するとき

- 画面識別の条件を変えたとき
